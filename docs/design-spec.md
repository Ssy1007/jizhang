# 设计规范文档

## 设计原则
- **简洁至上**：每个页面核心操作不超过3个
- **直观可预测**：按钮位置、颜色含义保持一致
- **大触控区域**：所有可点击元素不小于 44×44px（符合 iOS/Android 触控规范）
- **渐进呈现**：先展示汇总数据，再允许深入查看详情

## 字体
- 系统默认字体（-apple-system, sans-serif）
- 金额数字使用等宽字体特征（font-variant-numeric: tabular-nums）
- 最小字号不小于 14px

## 页面结构

### 首页（记账 + 概览）
```
┌──────────────────────────────┐
│  [当月]  总支出 ¥xxx  总收入 ¥xxx │  ← 汇总卡片
│  预算进度条                    │
├──────────────────────────────┤
│  [日] [周] [月] [年]          │  ← 时间维度切换
├──────────────────────────────┤
│  分类占比环形图/进度条          │
├──────────────────────────────┤
│  + 记一笔                     │  ← FAB浮动按钮
├──────────────────────────────┤
│  最近交易列表（按日期分组）      │
└──────────────────────────────┘
```

### 底部导航栏
```
┌─────────┬─────────┬─────────┬─────────┐
│  首页   │  统计   │  搜索   │  设置   │
│  🏠    │  📊    │  🔍    │  ⚙️    │
└─────────┴─────────┴─────────┴─────────┘
```

### 记一笔弹窗（底部弹出）
```
┌──────────────────────────────┐
│  记一笔              [×]     │
├──────────────────────────────┤
│  [支出] [收入]               │  ← 类型切换
├──────────────────────────────┤
│  金额：¥ ___                 │
│  分类：[日常][社交][交通]...  │  ← 横向滚动
│  日期：2026-05-16           │
│  备注：___                  │
├──────────────────────────────┤
│         [保存]               │
└──────────────────────────────┘
```

### 统计页
- 顶部：时间段选择器（本月/本周/本年等）
- 中间：分类饼图（用CSS/SVG实现简单饼图）
- 下方：各类别排行榜列表

### 搜索页
- 顶部搜索框
- 分类快捷筛选标签
- 搜索结果列表

### 设置页
- 主题颜色切换（色块选择）
- 分类管理入口
- 每月预算设置
- 数据管理（清除全部数据 - 带二次确认）
- 关于信息

## 交互规范
- 所有弹窗从底部滑入（类似原生APP体验）
- 删除操作需二次确认
- 金额输入自动聚焦数字键盘（inputmode="decimal"）
- 下拉刷新（可选）
- 添加记录后给出轻微振动反馈（navigator.vibrate）
