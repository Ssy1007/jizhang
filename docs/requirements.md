# 项目需求文档

## 项目概述
项目名称：记账APP（待命名）
项目类型：PWA 渐进式网页应用
目标平台：Android、iOS（通过浏览器访问，可添加到手机桌面）
开发方式：纯前端（HTML + CSS + JavaScript），单文件部署

## 功能需求

### F1 - 记支出
- 输入金额
- 选择分类（日常、社交、交通、餐饮、网购、其他）
- 可选备注文字
- 默认日期为当天，可手动修改
- 保存后出现在记录列表中

### F2 - 记收入
- 输入金额
- 可选备注文字
- 默认日期为当天，可手动修改
- 保存后出现在记录列表中

### F3 - 账单视图
- 提供日/周/月/年四种时间维度切换
- 每个维度显示对应时间段的汇总数据
- 自动计算：总支出、总收入、结余
- 默认显示当月视图

### F4 - 消费详情
- 每条记录显示：金额、分类、备注、日期
- 支持展开查看完整详情
- 支持删除记录（滑动删除或按钮删除）
- 支持编辑已有记录

### F5 - 搜索功能
- 按备注关键字搜索
- 按分类筛选
- 搜索结果高亮显示

### F6 - 分类管理
- 默认6个支出分类：日常、社交、交通、餐饮、网购、其他
- 支持新增自定义分类
- 支持删除分类（已有记录的分类不可删除，或提示用户）
- 每个分类可设置颜色标签

### F7 - 预算提醒
- 可设置每月支出预算上限
- 当月支出超出预算时，弹窗/通知提醒
- 在首页显示预算进度条

### F8 - 数据存储
- 所有数据存储在浏览器 localStorage
- 不需要后端、不需要网络
- 首次打开自动初始化默认数据

### F9 - 主题切换
- 默认主题色：淡绿色 (#e8f5e9 / #81c784)
- 设置页面提供备选配色：浅蓝、浅粉、浅紫、经典白
- 主题选择存储在 localStorage

## 非功能需求

- 页面加载时间 < 2 秒
- 支持离线使用（PWA Service Worker）
- 响应式设计，适配不同手机屏幕尺寸（320px - 428px 宽度）
- 单页面应用，所有操作在一个 HTML 文件内完成
- 无第三方依赖，纯原生实现
